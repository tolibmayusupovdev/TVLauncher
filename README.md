# TVLauncherApp

Bu loyiha Android TV uchun maxsus ishlab chiqilgan Launcher ilovadir. Foydalanuvchi Android TV ishga tushganda ushbu ilovani default launcher sifatida tanlab, TV interfeysini sozlashi mumkin.

---

## APK fayl

> To'liq ishlaydigan `.apk` fayl `/app/release/app-debug.apk` manzilda joylashgan.

---

## Qurish uchun qo‘llanma

Agar siz loyihani o‘zingiz qurmoqchi bo‘lsangiz, quyidagi qadamlarni bajaring:

1. **Android Studio** dasturini oching.
2. Loyihani import qiling:  
   `File > Open > TVLauncherApp` (loyiha papkasini tanlang)
3. Yuqoridan **Build > Clean Project** bosing.
4. So‘ng **Build > Rebuild Project** buttonni bosing.
5. Build muvaffaqiyatli yakunlangach:  
   **Build > Build Bundle(s) / APK(s) > Build APK(s)** tugmasini bosing.
6. APK fayl quyidagi joyda hosil bo‘ladi:  
   `app/build/outputs/apk/release/app-debug.apk`
